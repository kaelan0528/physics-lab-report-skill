# 最终 QA 清单

每项记录 PASS / FAIL / 不适用 / 未验证及证据。未验证不能写 PASS；失败项标明影响和待办。此清单独立于实验报告正文。

## 数据

- [ ] 使用已核准的冻结版本；原始数据、表格与冻结文件一致。
- [ ] 原始读数与现场派生值分开；歧义已人工确认，尾随零和单位保留。
- [ ] 不同页面的数值一致；独立验算有独立方法及证据。
- [ ] 未静默删除异常值；坏值方法有依据和适用条件。

## 公式与单位

- [ ] 方法符合本次教材，未用模板物理结论替代。
- [ ] 量纲、换算、数量级与有效数字正确，无中间过早舍入。
- [ ] 独立公式为真正 OMML 分式、根号、上下标，无普通文本假公式或截图替代。
- [ ] 公式语义、求和范围、下标及数值与计算产物一致。

## 不确定度

- [ ] 修正量与仪器误差限区分；修正量没有当随机分量重复加入。
- [ ] A 类基于适用数据；B 类参数、分布和来源明确，无未解释数值。
- [ ] 标准/扩展不确定度与 Δ 定义一致，相关性及覆盖因子按依据处理。
- [ ] 传播式与教材一致，前后使用的各分量和最终结果一致。

## 图表

- [ ] 只做必要图表；中文图题、坐标单位、方程单位一致。
- [ ] 拟合仅按指定作用使用，R² 未被当准确度证明。
- [ ] 数据完整、数字不被拆行；小表无异常跨页；cantSplit 不被误称为整表同页保证。
- [ ] 图片完整清晰、不越界；图中文字可读。

## 正文与 Word

- [ ] 结果分析与教材思考题有依据，无猜测材料或标准值。
- [ ] 没有 Step / Codex / JSON / workspace 等工作流痕迹（确为实验术语时除外）。
- [ ] 保留授权外内容与目标标题、字体、字号，备份可用。
- [ ] 无不需要的 bullet、List Paragraph 或正文 keepNext 链；已检查样式继承，正常编号保留。
- [ ] 黑点已区分为列表或非打印格式标记，没有盲目删除分页属性。
- [ ] DOCX 可重新打开，ZIP、XML、关系引用、图片无损坏或缺失。

## 隐私

- [ ] 公开示例为虚构，无个人身份信息、私有资料、绝对本机路径。
- [ ] 公开文件与元数据、版本历史均已检查；未上传用户资料到外部服务。

## 真实视觉 QA

- [ ] 已记录实际渲染器、渲染成功证据和实际页数，未使用缓存页数冒充。
- [ ] 逐页查看标题孤立、公式、表格、图片、字体、空白、分页及末页。
- [ ] 渲染失败时明确写“只完成结构检查，未完成真实视觉检查。”
- [ ] 最终交付说明检查范围和限制，不宣称未经验证的网站兼容性。
