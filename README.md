# physics-lab-report-skill

这是一个面向大学物理实验报告的 agent-agnostic workflow / skill specification。它把材料审计、数据冻结、计算验证、不确定度处理、按需绘图、报告写作和最终 QA 组织成一套可复用工作流，不预置任何具体实验答案。

核心内容由以下文件组成：

- `SKILL.md`：工作流与执行规则。
- `templates/data-freeze-schema.json`：冻结原始数据、来源、确认状态和不确定度信息的 JSON Schema。
- `templates/final-qa-checklist.md`：交付前检查清单。
- `examples/example.md`：遇到歧义时暂停询问的虚构示例。

本项目不依赖某一个特定 AI 产品。Codex 只是其中一种使用方式；任何能够遵循仓库级指令的兼容 AI agent 都可以使用这套工作流。

## 能做什么与适用场景

适用于有实验指导书与测量记录的大学物理实验报告，也可只处理数据核验、不确定度或已有 Word 的局部修订。支持材料审计、数据冻结、独立验算、按需坏值判断、A/B 类不确定度、修正量处理、绘图、结果分析、教材思考题和专业 Word 公式。

## 兼容条件

只要所使用的 AI agent 能够完成以下工作，就可以采用本工作流：

- 读取本仓库文件和 `SKILL.md`；
- 接收实验指导书、原始记录、图片、旧报告和目标模板；
- 执行计算、单位检查和独立交叉验证；
- 发现信息不明确、资料冲突或关键参数缺失时主动询问，而不是自行猜测。

如果需要直接生成或修改 Word，agent 还需要具备 DOCX 编辑能力，并能正确处理 Office Math / OMML。并非所有 agent 都支持这些能力；没有相应能力时，应明确报告限制，不能声称已经完成真实 Word 或视觉 QA。

## 通用使用方式

1. 下载或 clone 本仓库。
2. 将仓库，或至少将 `SKILL.md` 及其所需模板提供给所使用的 AI agent。
3. 要求 agent 先阅读 `SKILL.md`，理解本次任务的阶段和停止条件。
4. 再提供本次实验的指导书、原始数据或照片、可选旧报告、目标 Word 模板，以及教师或课程的额外要求。
5. 要求 agent 按工作流分阶段执行；材料有歧义时先暂停询问，确认后再冻结数据和继续计算。

## Example: Codex

在 Codex 或其他兼容 AI agent 中，可以这样开始：

> 使用 physics-lab-report-skill，根据我上传的实验资料完成实验报告。教材优先于通用知识，旧报告只作为格式和处理方式参考。先审计材料，不要一次性写完。

这是推荐的逐步模式。每一步完成后，你可以核对再继续。若希望连续处理，可说：

> 使用 physics-lab-report-skill，按完整流程完成报告。遇到模糊数据、缺失参数或方法冲突先问我；其余阶段连续执行。保留原稿，输出新 Word。

局部修订可说：

> 只核对不确定度参数及其传播，列出依据和待确认项，暂不修改 Word。

## 推荐上传材料

通常需要提供：

- 本次实验教材 / 指导书；
- 原始数据、清晰照片或扫描件；
- 旧报告模板（可选）；
- 目标 Word 模板或空白报告。

可另外提供教师要求、仪器说明和指定字体。照片须包含表头、单位和备注。

## 工作流

材料审计 → 原始数据冻结 → 计算与独立验算 → 按要求坏值判断 → 不确定度 → 按需绘图 → 正文撰写 → Word 与 Office Math → 最终 QA。

核准后生成 `data_freeze.json`，后续计算只读取这个冻结版本，避免反复 OCR 引入变化。坏值判断与绘图并非每个实验都必需。流程示例见 [虚构示例](examples/example.md)。

## 什么时候会暂停询问

看不清的数据、缺失的仪器参数、含义不明确的数值、不确定度分布不清、教材与记录冲突，或不同资料规定了不同处理方法时，agent 应说明具体问题并暂停相关工作，不能自行猜测。旧报告只能作为格式、处理方式和表达风格参考，不能复制其中的数据或物理结论。

## 已知限制

不同学校规则不完全一致，本工作流不保证自动满足所有课程要求。教师和本校教材优先于通用做法。

本项目是工作指导，不是自带的 OCR、计算器、Word 编辑器或渲染服务。OMML、图像检查与真实渲染需要宿主环境支持；没有渲染条件时必须明确报告“只完成结构检查，未完成真实视觉检查。”结构完整也不能保证学校预览服务器兼容。自动处理仍需要用户检查最终文档。

## 隐私

公开仓库只应包含工作流、通用模板和完全虚构的示例。不要把个人身份信息、真实记录、课程私有资料或生成报告提交到公开仓库。忽略规则仅减少误提交，不能清除已经被 Git 跟踪的文件，也不会覆盖历史记录。公开前应检查文件、元数据和提交历史。
