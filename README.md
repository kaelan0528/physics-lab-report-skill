# physics-lab-report-skill

一个面向大学物理实验报告的 Codex / Agent Skill。它提供从资料核准到 Word 成品的可靠工作流程，不预置具体实验答案。教材和用户资料优先。

## 能做什么与适用场景

适用于有实验指导书与测量记录的大学物理实验报告，也可只处理数据核验、不确定度或已有 Word 的局部修订。支持材料审计、数据冻结、独立验算、按需坏值判断、A/B 类不确定度、修正量处理、绘图、结果分析、教材思考题和专业 Word 公式。

## 安装

下载本仓库，将包含 `SKILL.md` 的整个文件夹命名为 `physics-lab-report`，复制到 Codex 的个人技能目录 `~/.codex/skills/`。若已自定义技能目录，使用自己的配置。重新启动会话，确认技能可被识别。不要覆盖已有同名技能而不备份。

其他支持 Agent Skills 的工具，按该工具的技能导入方式导入同一文件夹。仓库文件夹名可为 `physics-lab-report-skill`，安装时技能文件夹名使用 `physics-lab-report`。本项目不附带 Word、Python 或渲染器；实际执行能力由宿主工具提供。

## 推荐上传材料

用户通常只需上传：

- 本次实验教材 / 指导书。
- 原始数据、清晰照片或扫描件。
- 旧报告模板（可选）。
- 目标 Word 模板或空白报告。

可另外提供教师要求、仪器说明和指定字体。照片须包含表头、单位和备注。

## 使用方法与最小示例

在可访问上述资料的会话中说：

> 使用 physics-lab-report skill，根据我上传的材料完成实验报告。教材优先于通用知识。旧报告只作为格式和处理方式参考。先做材料审计，不要一次性写完。

这是推荐的逐步模式。每一步完成后，你可以核对再继续。若希望连续处理，可说：

> 使用 physics-lab-report skill，按完整流程完成报告。遇到模糊数据、缺失参数或方法冲突先问我；其余阶段连续执行。保留原稿，输出新 Word。

局部修订可说：

> 只核对不确定度参数及其传播，列出依据和待确认项，暂不修改 Word。

## 工作流

材料审计 → 原始数据冻结 → 计算与独立验算 → 按要求坏值判断 → 不确定度 → 按需绘图 → 正文撰写 → Word 与 Office Math → 最终 QA。

核准后生成 `data_freeze.json`，后续计算只读取这个冻结版本，避免反复 OCR 引入变化。坏值判断与绘图并非每个实验都必需。流程示例见 [虚构示例](examples/example.md)。

## 已知限制

不同学校规则不完全一致，本 Skill 不保证自动满足所有课程要求。教师和本校教材优先于通用做法。看不清的数据、缺失的仪器参数或不明确的不确定度分布必须确认，不能推测。

Skill 是工作指导，不是自带的 OCR、计算器或 Word 转换服务。OMML、图像检查与真实渲染需要宿主环境支持；没有渲染条件时会明确报告“只完成结构检查，未完成真实视觉检查。”结构完整也不能保证学校预览服务器兼容。自动处理仍需要用户检查最终文档。

## 隐私

仓库只包含工作流、通用模板和虚构示例。不要把个人身份信息、真实记录、课程私有资料或生成报告提交到公开仓库。忽略规则仅减少误提交，不能清除已经被 Git 跟踪的文件，也不会覆盖历史记录。公开前检查文件、元数据和提交历史。

## 仓库内容

- `SKILL.md`：代理执行规则。
